Entry for make.fun bounty **One Line, One Laugh** ($2 pool, top 10): one
original funny line, at most 140 characters, judged pairwise by a stand-up
comedy editor judge that keeps the bigger laugh.

`main.py` (Python 3, standard library only) writes one line to
`/output/entry.txt`:

> My therapist told me to talk to my plants. Now the fern knows too much, and the cactus is blackmailing me.

The line is a fixed string: no randomness, no network, no model calls,
so both runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
